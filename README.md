# Zaira Masala - Proyecto de Desarrollo Web 🍛

¡Hola! Este es mi proyecto para la clase de desarrollo web de primer año. He diseñado y programado una página web estática para un restaurante indio llamado **Zaira Masala**.

## 💻 Tecnologías que he utilizado

Para construir esta web he aplicado lo que estamos aprendiendo en el curso:
- **HTML5:** Para estructurar todo el contenido de la página utilizando etiquetas semánticas.
- **CSS3:** Para darle estilo, crear el modo oscuro y hacer que se adapte a teléfonos móviles y tablets (responsive design).
- **JavaScript:** Para añadir algo de interactividad básica, como el menú de navegación y un pequeño carrito que lee los platos desde un archivo JSON.

## 🚀 Cómo probar el proyecto

Es muy sencillo, no necesitas instalar ningún servidor ni programa especial:

1. Clona este repositorio o descarga el código como archivo ZIP.
2. Descomprime la carpeta en tu ordenador.
3. Haz doble clic en el archivo `index.html` para abrirlo en tu navegador favorito (Chrome, Firefox, etc.).

También puedes ver el proyecto funcionando en vivo a través de GitHub Pages (si lo tengo activado en la configuración del repositorio).

## 📝 Sobre el código

He intentado mantener el código ordenado:
- El CSS está separado en la carpeta `css/` (`styles.css` y `additional.css`).
- He usado variables de CSS para que sea más fácil cambiar los colores principales.
- Los datos del menú están en un archivo separado (`menu.json`) para no mezclar contenido con estructura.
